## RED #5 — Hyperparameters (`04-methodology.tex`, the `\newexp` block)  ✅ DONE

Exact released configuration (`disco/run_experiment.py::DEFAULTS`):

- Association threshold **δ_thresh = 0.30**; max retained dependency pairs **k = 8**.
- Discriminator reward weights **λ_token = λ_sent = λ_feat = λ_row = 0.25** (uniform);
  discriminator loss weights **μ_k = 1**.
- IFRS scaling **α = 0.2**.
- Generator SFT: AdamW, lr **5×10⁻⁵**, batch 16, epochs adaptive to N
  (≤500→50, ≤2000→30, else 10).
- PPO: lr **5×10⁻⁶**, clip **ε = 0.1**, KL coeff **β = 0.5** with a KL-target
  early-stop at 0.5, value coeff **c_v = 0.1**, **2** optimizer epochs/step,
  **40** PPO steps, rollout batch 32.
- Discriminators: AdamW lr **2×10⁻⁴**; D_sent uses a frozen DistilBERT encoder
  (a lighter stand-in for BERT-base) + trainable head; D_token a BiLSTM; D_feat/
  D_row MLP heads on the generator's last-layer hidden states.

Sensitivity analysis (α, λ_k ± perturbation): see `disco/tables/sensitivity_*`
(generated by the sensitivity sweep; fill the ± F1 numbers from that output).
