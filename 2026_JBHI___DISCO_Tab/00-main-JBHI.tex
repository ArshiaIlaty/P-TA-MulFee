\subsection{Code and Data Availability}
\label{sec:code}
The full pipeline, all synthetic-data evaluation code, and the complete per-dataset benchmark for every generator and metric are publicly available at \url{https://github.com/ArshiaIlaty/DISCO-TAB} to support reproducibility and reuse.

\subsection{Implementation and Computational Resources}
\label{sec:implementation}
All experiments ran on a single node with one NVIDIA T4 GPU (16~GB); DISCO-TAB's GPT-2 backbone and lightweight discriminator heads keep it within this budget, reflecting the modest hardware common in clinical computing environments. The framework is implemented in Python with PyTorch, using the Hugging Face \texttt{transformers} library for the GPT-2 backbone and a customized Proximal Policy Optimization loop; baselines use their authors' released implementations under the shared evaluation protocol. The complete hyperparameter configuration is given in Section~\ref{sec:methodology}, and exact library versions are pinned in the released environment files.
